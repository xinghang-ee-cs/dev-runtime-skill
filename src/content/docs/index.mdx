这套教程围绕仓库中的四个 Runtime Skill 展开。你可以从完整流程开始，也可以只使用独立的代码检查流程。

## 开发主流程

<Steps>

1. **规划**：确认需求、范围、验收标准与执行交接。
2. **开发和自动化验证**：依据已确认的交接完成实现，直到 `ready_for_local_test`。
3. **人工及真实环境测试**：继承自动化证据，完成人工、设备、云端或外部能力验证。
4. **发布与安全流程**：交给目标项目自己的发布门禁，不由本仓库批准上线。

</Steps>

## 从这里开始

<CardGrid>
  <Card title="第一次安装" icon="rocket">
    把完整的 Skill 目录部署到目标项目，并配置项目级 `AGENTS.md`。

    [阅读安装教程](./tutorials/getting-started/)
  </Card>
  <Card title="判断使用哪个 Skill" icon="puzzle">
    根据当前任务所处阶段选择唯一的负责人，避免规划、实现和验收职责混在一起。

    [查看选择指南](./tutorials/choosing-a-skill/)
  </Card>
  <Card title="走通完整流程" icon="setting">
    从规划交接开始，一直推进到发布材料移交。

    [进入工作流教程](./tutorials/full-workflow/)
  </Card>
  <Card title="查看规则源文件" icon="document">
    教程用于理解和上手；实际运行时以仓库中的 `SKILL.md` 和按需加载的 references 为准。

    [浏览 Skill 目录](./reference/skill-catalog/)
  </Card>
</CardGrid>

:::note[教程与规则的关系]
教程不会复制完整运行时规则。规则发生变化时，应先更新 `skills/` 下的源文件，再同步修订受影响的教程。
:::
