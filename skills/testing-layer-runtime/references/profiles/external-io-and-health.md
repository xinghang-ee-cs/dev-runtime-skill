# 外部 I/O 与健康探针检查

存在外部请求、流式消费或服务探针时加载。上限和成功语义来自合同、协议与当前项目事实，不从本示例猜测。

- 验证响应体实际累计字节数受限；只检查 Content-Length 不能覆盖缺失/伪造长度、chunked/流式数据或解压后放大。按项目实际解压与解析路径检查内存、解析和累计输出边界。
- 检查连接/读取/总体时限、取消传播、有限重试、连接释放和错误输出；无界外部响应不能因 HTTP 成功就算业务成功。
- 在隔离测试端点复现慢响应、超大响应、截断、无长度流、错误状态码和依赖不可达；按合同验证拒绝/中止/恢复及其他请求不受拖垮。不得向未授权第三方施压。
- 区分存活、就绪和业务健康；响应内容、状态码和关键依赖应共同满足本项目探针合同。网络命令退出 0 不必然代表 HTTP 成功，例如普通 curl 接到 503 仍可能成功退出；核对项目采用的失败状态判定或显式状态码断言。
- 若项目允许重定向、认证或特定非 2xx 成功码，按实际合同设计断言，不机械规定所有项目只接受 200。
- 将错误码、大小和超时处理的行为测试映射到 CI；编译/类型检查不能替代这些测试。部署后再核对真实代理、运行配置和依赖环境下的表现。
