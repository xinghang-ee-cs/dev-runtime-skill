# Profile 模板

```yaml
profile_type: null
profile_id: null
activation: {}
applies_to_steps: []
```

## 触发条件

说明环境档案中的哪些字段值会激活本 Profile，以及需要用哪些仓库事实复核。未满足条件时不得加载。

## 命名与目录

只记录该技术栈特有的命名、目录和放置规则；优先服从目标项目已有约定。

## 架构边界

只记录该技术栈真实存在的等价对象和边界，不要求未采用该结构的项目新增分层。

## 测试要求

说明对已有测试体系的附加要求，不引入新的测试框架。

## 构建与验证

说明应从环境档案读取哪些命令，以及技术栈特有的验证关系。

## Generated Artifact 或迁移

说明生成物、schema 或 migration 的处理规则；没有特有规则时写“不适用”，不要编造内容。

## 不适用时

说明如何跳过本 Profile，同时继续执行通用 Step。

本模板不得增加模式、范围、修改授权、`继续` gate、Runtime 状态或问题分类。
